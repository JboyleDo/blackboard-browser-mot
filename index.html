🎓 Blackboard Browser MOT v1.5.1

A guided Blackboard browser diagnostic. The MOT tests browser behaviours it can measure, identifies likely client-side issues, links to the relevant browser guidance, and provides a diagnostic report for escalation if the problem remains.

Version 1.5 keeps the genuine cross-site cookie test and restores automatic pop-up behaviour as a scored browser check. Blackboard's own site-specific pop-up permission remains a separate manual check because a local diagnostic cannot read another site's Edge permission directly.

Manual checks the MOT cannot complete for you

Cache / Blackboard site data: the MOT cannot reliably determine whether Blackboard is using stale cached files, cookies, site data or authentication state, and it cannot clear another website's stored data. If the issue remains after resolving any detected failure, clear browser cache and cookies/site data manually, close and reopen the browser, and test Blackboard again.

Still not working?

If you have followed the recommended guidance, cleared browser cache/site data and the Blackboard issue still occurs, copy the diagnostic report and contact itonline@uwe.ac.uk.

The email button opens a new message with the issue summary and escalation wording. The full diagnostic is copied to your clipboard so you can paste it into the email.
